# Landing — Lic. Analía Lima

Sitio estático listo para probar localmente o desplegar en Vercel.

## Probar localmente

Abrí la carpeta en Visual Studio Code y ejecutá:

```bash
npm install
npm run dev
```

Luego abrí la dirección que aparezca en la terminal. También podés usar la extensión **Live Server** sobre `index.html`.

## Formulario

Al enviar, abre la aplicación de correo predeterminada con un mensaje dirigido a `lima.analia2022@gmail.com` y los campos completos. No requiere claves, servicios externos ni configuración adicional.

## Desplegar en Vercel

Subí esta carpeta a un repositorio de GitHub e importalo desde Vercel. Vercel detectará Vite automáticamente y ejecutará `npm run build`.
